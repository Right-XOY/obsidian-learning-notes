# QKV（Query，Key，Value）

当你在某电商平台搜索某件商品（年轻女士冬季穿的红色薄款羽绒服）时，你在搜索引擎上输入的内容便是Query。 然后搜索引擎根据Query为你匹配Key（例如商品的种类，颜色，描述等）。 然后根据Query和Key的相似度得到匹配的内容（Value)。


用公式定义，给定输入矩阵 $\boldsymbol{X}$（$n$ 个 token，每个 $d$ 维），分别乘三个可学习的权重矩阵，投影出 Q、K、V：

$$
\boldsymbol{Q}=\boldsymbol{X}\boldsymbol{W}_Q,\qquad \boldsymbol{K}=\boldsymbol{X}\boldsymbol{W}_K,\qquad \boldsymbol{V}=\boldsymbol{X}\boldsymbol{W}_V
$$

其中：
- $\boldsymbol{Q}$（Query，查询）：当前 token 想「找什么」
- $\boldsymbol{K}$（Key，键）：每个 token 的「标签/索引」，供查询去匹配
- $\boldsymbol{V}$（Value，值）：每个 token 真正要「取出的内容」
- $\boldsymbol{W}_Q,\boldsymbol{W}_K,\boldsymbol{W}_V$：三个可学习参数矩阵（序列内不同位置的 token 共享）

> 核心思想：**用 Q 去匹配 K，得到注意力权重，再用这个权重去加权 V**，最终得到「哪些信息更值得关注」的输出。

**softmax 函数**：把一组分数变成概率分布（每个值落在 $(0,1)$，且总和为 1）：

$$
\mathrm{softmax}(x_i)=\frac{e^{x_i}}{\sum_j e^{x_j}}
$$

注意力里用 softmax，正是要把「Q 与各 K 的相关度分数」归一化成「注意力权重」。

> softmax 在多分类交叉熵里也用到，见 [[损失函数]]。

把上面的过程写成**缩放点积注意力**的标准公式：

$$
\mathrm{Attention}(\boldsymbol{Q},\boldsymbol{K},\boldsymbol{V})=\mathrm{softmax}\!\left(\frac{\boldsymbol{Q}\boldsymbol{K}^\mathrm{T}}{\sqrt{d_k}}\right)\boldsymbol{V}
$$

分四步理解：

1. **算相似度**：$\boldsymbol{Q}\boldsymbol{K}^\mathrm{T}$，用点积衡量每个 Q 与每个 K 的相关程度；
2. **缩放**：除以 $\sqrt{d_k}$（$d_k$ 是 K 的维度）。维度越大点积越大，会推到 softmax 的饱和区导致梯度消失，除以 $\sqrt{d_k}$ 可以缓解；
3. **softmax**：把每一行的分数归一化成权重（每行和为 1）；
4. **加权求和**：用权重对 $\boldsymbol{V}$ 加权，得到输出。

第 $i$ 个 token 的注意力权重与输出为：

$$
\alpha_{ij}=\frac{\exp\!\big(q_i\cdot k_j/\sqrt{d_k}\big)}{\sum_{j'}\exp\!\big(q_i\cdot k_{j'}/\sqrt{d_k}\big)},\qquad b_i=\sum_j \alpha_{ij}\,v_j
$$

其中：
- $\alpha_{ij}$：第 $i$ 个 token 对第 $j$ 个 token 的注意力分数（即你说的 $\alpha_i$，满足 $\sum_j\alpha_{ij}=1$）
- $b_i$：第 $i$ 个 token 加权后的新表示

> 自注意力的「自」体现在：**Q、K、V 都来自同一个序列**，让每个 token 都能直接和序列里所有 token 交互，捕捉远距离依赖。

# 多头注意力机制

单头注意力只能学到一种「关注模式」。多头注意力把 Q、K、V 拆成 $h$ 份（称为 $h$ 个头），各自独立算注意力，最后拼接再投影：

$$
\mathrm{head}_i=\mathrm{Attention}\big(\boldsymbol{Q}\boldsymbol{W}_i^Q,\ \boldsymbol{K}\boldsymbol{W}_i^K,\ \boldsymbol{V}\boldsymbol{W}_i^V\big)
$$

$$
\mathrm{MultiHead}(\boldsymbol{Q},\boldsymbol{K},\boldsymbol{V})=\mathrm{Concat}(\mathrm{head}_1,\dots,\mathrm{head}_h)\,\boldsymbol{W}^O
$$

其中：
- 每个头有自己独立的 $\boldsymbol{W}_i^Q,\boldsymbol{W}_i^K,\boldsymbol{W}_i^V$，把向量投影到不同子空间
- 各头算出的结果沿最后一个维度**拼接**，再用 $\boldsymbol{W}^O$ 投影回原维度

> 好处：不同头可以关注不同关系（如一个头关注「主谓」，一个头关注「修饰/指代」），拼接后表达能力更强。Transformer 原文用的是 $h=8$。



# 掩码 （因果）自注意力机制

在**解码器**生成下一个 token 时，只能看到「当前位置及之前」的内容，不能偷看未来 token（否则等于作弊）。

做法：在 softmax 之前，把未来位置的分数置为 $-\infty$，这样 softmax 之后它们的权重就是 0。

掩码矩阵（上三角为 $-\infty$）：

$$
\begin{bmatrix}
0 & -\infty & -\infty\\
0 & 0 & -\infty\\
0 & 0 & 0
\end{bmatrix}
$$

> 「因果」的含义：当前位置只由过去决定，不依赖未来，保证生成是自左向右、符合因果的。这也是 GPT 这类「因果解码器」的核心。



# 交叉注意力机制

交叉注意力与自注意力的区别在于 Q、K、V 的**来源**：

- **自注意力**：Q、K、V 来自**同一序列**
- **交叉注意力**：Q 来自一个序列，K、V 来自**另一个序列**

典型出现在 Transformer 的**解码器**里：Q 来自解码器自身（当前要生成的内容），K、V 来自编码器的输出（源序列）。

$$
\mathrm{CrossAttention}=\mathrm{softmax}\!\left(\frac{\boldsymbol{Q}_\text{dec}\,\boldsymbol{K}_\text{enc}^\mathrm{T}}{\sqrt{d_k}}\right)\boldsymbol{V}_\text{enc}
$$

> 作用：让解码器在生成时能「回头看」编码器提取的源序列信息，实现两种序列之间的信息交互。
