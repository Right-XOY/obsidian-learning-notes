# ==一、什么是 Bootstrap==

Bootstrap（自助抽样法 / 自助法）是一种**有放回重采样**的统计方法，用来估计某个统计量的**分布**（标准误、置信区间等）。

核心场景：手里只有一份样本，不知道总体分布，却想知道某个统计量（均值、AUC、中位数等）到底有多可靠。

> 一句话：**用样本「模拟」总体，反复有放回抽样，估计统计量的波动范围。**

# ==二、核心思想==

从容量为 $n$ 的原始样本中，**有放回**地随机抽取 $n$ 次，得到一个 Bootstrap 样本。

因为有放回，Bootstrap 样本和原样本**一样大**（都是 $n$），但内容不同——有的样本被重复抽到，有的被漏掉。这相当于模拟了一次「从总体重新抽样」。

重复 $B$ 次，得到 $B$ 个 Bootstrap 样本，每个样本算一个统计量，就得到了该统计量的**经验分布**。

# ==三、算法步骤==

1. 记原始样本为 $\{x_1,x_2,\dots,x_n\}$；
2. 有放回地抽取 $n$ 次，得到一个 Bootstrap 样本 $b$（可能有重复、有缺失）；
3. 计算该样本上的统计量 $\hat\theta_b$（如均值、AUC）；
4. 重复第 2–3 步共 $B$ 次（通常 $B\ge 1000$）；
5. 得到 $\{\hat\theta_1,\hat\theta_2,\dots,\hat\theta_B\}$，用它来估计 $\hat\theta$ 的标准误与置信区间。

# ==四、置信区间（百分位法）==

最常用的是**百分位法**（percentile method）：

- 把 $B$ 个 $\hat\theta_b$ 从小到大排序；
- 取第 $2.5\%$ 分位数作为区间下限、第 $97.5\%$ 分位数作为上限，即得 $95\%$ 置信区间：

$$
CI_{95\%}=\Big[\ \hat\theta_{(2.5\%)},\ \hat\theta_{(97.5\%)}\ \Big]
$$

> 例如 [[ROC曲线与AUC值]] 里算 AUC 的 95% 置信区间，正是这个做法：在测试集上做 $B$ 次有放回重采样，每次算一个 AUC，再取 2.5% 和 97.5% 分位数。

# ==五、一个重要特性：63.2% 覆盖率==

有放回抽 $n$ 次，某个原始样本**一次都没被抽到**的概率为：

$$
\left(1-\frac{1}{n}\right)^n \xrightarrow{\ n\to\infty\ } e^{-1}\approx 0.368
$$

所以平均每个 Bootstrap 样本只包含约 **63.2%** 的原始样本，其余 36.8% 是重复项。

那些没被抽到的样本称为**袋外数据（OOB，Out-Of-Bag）**，随机森林就利用 OOB 做无偏的模型验证。

# ==六、应用与注意事项==

**典型应用：**
- 模型评估：AUC、准确率等指标的置信区间（见 [[ROC曲线与AUC值]]）
- 比较两个模型的指标是否有显著差异：[[DeLong检验]]
- 任何没有解析分布的统计量，都能用它估计标准误

**优点：**
- 非参数，不假设总体服从某个分布
- 通用性强，几乎任何统计量都适用

**缺点：**
- 计算量大（要重复 $B$ 次、每次重算统计量）
- 原始样本量 $n$ 太小时，抽样偏差可能被放大
