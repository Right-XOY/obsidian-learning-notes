# Obsidian 学习笔记

个人学习笔记，基于 [Obsidian](https://obsidian.md) 维护，Markdown 编写，按学科与主题分目录组织，内容持续完善中。

## 结构说明

- 笔记按学科分类存放，每个学科下按专题分子目录
- 使用 Markdown 编写，数学公式采用 LaTeX 语法
- 正在持续补充完善中，内容会不定期更新

## 使用建议

推荐使用 Obsidian 打开本仓库阅读，可正常渲染 Wiki 链接、公式与内嵌图片；纯 Markdown 查看器也可阅读大部分内容。
